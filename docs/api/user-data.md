# User Data API

## `GET /api/v1/tracking-records`

Danh sách hồ sơ theo dõi.

## `POST /api/v1/tracking-records`

Tạo hồ sơ theo dõi.

## `GET /api/v1/bookmarks`

Danh sách mục đã lưu.

## `POST /api/v1/bookmarks`

Lưu huyệt, phác đồ hoặc dụng cụ.

## `GET /api/v1/product-spec`

Metadata PRD, sitemap, màn hình, yêu cầu phi chức năng và tiêu chí MVP từ file DOCX.
